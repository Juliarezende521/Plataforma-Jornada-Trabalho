# Migrations

Os scripts SQL de negócio serão adicionados na etapa de modelagem. Não existe migration de negócio nesta base. Flyway e Hibernate estão configurados, mas isso não constitui validação de um schema nem persistência implementada.

Usar arquivos V1__descricao.sql, V2__descricao.sql etc. Não editar scripts já aplicados. Validar criação desde SQL Server vazio antes de considerar a persistência pronta.
